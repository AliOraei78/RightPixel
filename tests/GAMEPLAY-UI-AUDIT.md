# گزارش آزمون کامل مینی‌گیم‌ها

تاریخ: 2026-10-31

یک حساب مستقل با نام «بازیکن آزمایش رابط» و ایمیل `ui-audit-1793435362272@example.invalid` در نصب محلی ساخته شد. ورود، ذخیره‌ها، پاسخ‌سنجی و پیشرفت این حساب از API و PostgreSQL واقعی استفاده کردند. ایمیل آزمایشی ارسال نشد. اطلاعات ورود فقط در فایل محلی و خارج از Git، در `src/rightpixel-web/.e2e-data/audit-player.json` نگهداری می‌شود.

۳۹ اتاق پنج مرحلهٔ اول از طریق کنترل‌های مرورگر تکمیل شدند. این مسیر هر ۱۰ خانوادهٔ بازی را پوشش می‌دهد:

در هر خانواده، سؤال، انتخاب‌ها، مراحل چیدن پاسخ و نتیجه بررسی شدند. تمام صفحات انتخاب‌ها پیمایش شدند. پیش‌نمایش کد، کارگاه، ذخیره و بازیابی انتخاب‌ها و پیش‌نویس پس از refresh، و ادامهٔ دورهای باس نیز بررسی شدند. سرور درستی پاسخ‌ها و تکمیل اتاق‌ها را تأیید کرد؛ پاسخ‌سنجی شبیه‌سازی نشد.

معیارها شامل سرریز افقی، بریدگی کنترل‌ها، تداخل پنل و نوار ابزار، فاصله از شخصیت‌ها، ارتفاع ناحیهٔ خواندن، اندازهٔ هدف لمسی، اندازهٔ متن، کنتراست دکمه‌های فعال، جای کنترل‌های صفحه‌بندی و محدودهٔ پنجره‌ها بودند. تصاویر منتخب موبایل، تبلت، دسکتاپ و نمایشگر بزرگ نیز بازبینی شدند. نتیجهٔ نهایی آزمون واقعی: صفر ایراد ثبت‌شده و صفر خطای JavaScript.

## اعتبارسنجی و اجرای دوباره

- build، lint، format و ۱۴ آزمون رسانه پاس شدند.
- ۲۰ آزمون بک‌اند، شامل پیمایش ۳۱۲ اتاق با PostgreSQL مستقل و آزمون جدید بازپخش باس، پاس شدند.
- مجموعهٔ ۱۳۸ سناریوی مرورگر در Chrome، Firefox و WebKit با حالت‌های دسکتاپ و موبایل اجرا شد. دو تست Chrome موبایل هنگام به‌روزرسانی Vite قطع شدند؛ هر دو روی کد ثابت دوباره پاس شدند.
- آزمون‌های کنتراست کد انتخاب‌شده، وضعیت ذخیره و جای آن در سربرگ، و بازپخش کامل باس اضافه شدند.
- پس از آخرین اصلاح، هر ۱۸ آزمون مرتبط با کنتراست، کارگاه و هندسهٔ صحنه در هر شش حالت مرورگر دوباره پاس شدند.
- API و وب اصلاح‌شده در نصب محلی `http://localhost:8085` اجرا شدند. کانتینر مستقل دیتابیس آزمون پس از پایان حذف شد.

برای تکرار آزمون واقعی روی نصب محلیِ روشن:

```powershell
node tools/gameplay-audit.mjs
```

ابزار فقط میزبان محلی را می‌پذیرد و همان حساب آزمایشی را دوباره استفاده می‌کند. گزارش JSON و تصاویر در `tools/.course-checks/gameplay-audit/` نوشته می‌شوند؛ این پوشه خارج از Git است. تست‌های معمول مرورگر همچنان API را شبیه‌سازی می‌کنند و مستقل از این آزمون واقعی هستند.

تست روی گوشی یا تبلت فیزیکی و ارسال واقعی ایمیل انجام نشد. بازهٔ اندازه‌ها، آزمون مرورگر است و ادعای پوشش تمام دستگاه‌های ممکن نیست.
